# 📊 Swiggy Sales Analysis

End-to-End Sales & Business Analysis Project using Python

## 📌 About the Project

This project is a sales and business analysis of Swiggy data using Python.
The main goal of this project is to analyze sales performance across different time periods, geographic locations, and food categories, and extract meaningful business insights from the data.
The project covers the data analysis lifecycle — from data exploration and KPI analysis to data transformation, visualization, and business insight generation.

## 🎯 Project Objectives

- Analyze overall sales and order performance
- Identify monthly, weekly, daily, and quarterly sales trends
- Evaluate sales performance across different states and cities
- Compare revenue contribution between Veg and Non-Veg food categories
- Identify top-performing cities and geographic markets
- Analyze customer ratings and order-related KPIs
- Generate meaningful business insights from the analysis

## 📊 Dataset Details

## 📈 Key Insights

- Analyzed **197K+ records** of Swiggy sales data.
- Total analyzed sales were approximately **₹5.30 crore**.
- **Vegetarian food contributed approximately 65.2% of revenue**, while Non-Vegetarian food contributed 34.8%.
- **Karnataka** emerged as the highest-revenue state.
- **Bengaluru** was the highest-performing city among the cities analyzed.
- **Saturday** recorded the highest daily revenue, while Tuesday recorded the lowest.
- Q2 recorded the highest quarterly sales and order volume among the periods analyzed.
- Average ratings remained approximately **4.34** across the quarters analyzed.

## ⚠️ Data & Analysis Notes

- The dataset covers **January to August 2025**.
- Q3 2025 is a partial quarter in the dataset and should therefore be interpreted with caution.
- Veg and Non-Veg classification was performed using keyword-based rules applied to dish names. Therefore, some food items may not be classified perfectly.
